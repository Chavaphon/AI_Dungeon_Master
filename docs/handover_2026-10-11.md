## 9. Environment gotchas

- Always send `num_ctx` from `config/model.json` (8192). With no `num_ctx`, Ollama loads at 16384, spills 16% to the CPU and generates about ten times slower (`docs/hardware.md` §4).
- Every run starts from a freshly loaded model, and nothing else uses the Ollama server during it. Earlier requests to a loaded model can change a reply (`docs/model_selection.md` §3, CLAUDE.md §15 item 25).
- Send no `format` field (no JSON mode) on any request (CLAUDE.md §15 item 26).
- Never write the model name anywhere except `config/model.json`. `tests/test_model_config.py` fails if it appears in `adm/`.
- The first model load after a reboot takes about 35 s while the weights are read from disk. Later cold loads take about 7 s.
- On Windows with Git Bash, activate the venv with `source .venv/Scripts/activate`, not `.venv/bin/activate` as in CLAUDE.md §2.
- `runs/` and `results/` are gitignored. A run counts only once its `.jsonl` is on the Drive (`README.md`).
