# Abstract

<!-- WBS 11.12 · Owner: SD · Reviewer (11.6): CI · Outline: docs/report_outline.md, Abstract · Draft 2026-11-21 -->

Language-model Dungeon Masters narrate things the game state does not support, and this drift is rarely measured. This project built an autonomous Dungeon Master in which a local language model never writes to game state. The model proposes tool calls, a deterministic rules engine based on SRD 5.1 validates and executes them, and the model then narrates the outcome. Four conditions form a ladder of grounding: no state (A), the state in the prompt (B), the state plus a self-check (C) and the full engine (D). Each was run on 12 scenarios and 4 long sessions at three seeds with one 8-billion-parameter model on a laptop: 192 runs and 6,420 turn records, of which 2,124 narrated turns were labelled for divergence.

Grounding did not reduce divergence. D diverged at 57.4 per 100 narrated turns against 55.9 for A, a ratio of 1.03 (95% CI 0.74 to 1.48), so the hypothesis of a halving is not supported. Divergence did not grow over a session in any condition. No cost to narrative quality was detected, but the two raters did not agree. The engine kept the state legal in every turn, saved 86.6% of the turns with a rejected tool call within the retry budget, and met the latency target with a p95 of 7.89 s. Yet 70.2% of its executed calls did what the player asked, and its narration invented entities and misstated hit points as often as narration with no state. A validated engine makes the mechanics trustworthy, but not the prose. These results come from one small local model with no player study, and the M1 labels started from an AI draft.
